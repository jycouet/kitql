# @kitql/postgres-darwin-arm64

PostgreSQL 18.6.1 binaries for **darwin-arm64**, used by [`@kitql/postgres`](https://www.npmjs.com/package/@kitql/postgres).
Do not install it directly.

Built by [theseus-rs/postgresql-binaries](https://github.com/theseus-rs/postgresql-binaries/releases/tag/18.6.1),
stripped (no headers, static libs, nor bundled python) by `packages/postgres/scripts/platforms.js`.
